### 冷却は「あったほうがいい」ではなく必須

音声認識は CPU を数秒間 100% で回す処理です。Pi 5 は温度が上がると自動で
クロックを落とす（サーマルスロットリング）ので、**冷却しないと使っているうちに
どんどん返事が遅くなります。** しかも最初は速いので原因に気づきにくい。

公式アクティブクーラーを付けた場合、室温28℃・CPU 100% 負荷で 7分後に約70℃、
スロットリングは起きず 2.4GHz を維持します。これが欲しい状態です。

### 画面・キーボードは要らない

Raspberry Pi Imager で microSD を焼くときに **Wi-Fi の SSID/パスワードと SSH を
事前設定**できます。そうすれば電源を入れるだけで Wi-Fi に繋がるので、
Windows から SSH で入って作業できます。どうせ完成後はぬいぐるみの中に入って
画面など見られないので、最初からこの運用にしてしまうのが楽です。

ただし Wi-Fi 設定をミスすると何も手がかりが無くなるので、
micro-HDMI ケーブル（約1,000円）を保険として持っておくと安心です。

### なぜ 4GB で足りるのか

音声認識（faster-whisper small int8）が約0.5GB、VOICEVOX が約1GB。
アプリ本体は数十MBなので、4GB あれば余裕があります。
2026年はメモリ価格が上がっているので、8GB に払う価値は薄いです。

### なぜ Pi 4 ではなく Pi 5 なのか

**このロボットの応答速度は、ほぼ音声認識の速度で決まります。** whisper は GPU も
専用アクセラレータも使わず CPU で回るので、CPU 性能がそのまま「子供を待たせる秒数」
になります。

Pi 5 は Cortex-A76 2.4GHz、Pi 4 は Cortex-A72 1.5GHz で、**CPU 性能は 2〜3倍**の差。
メモリ帯域も約2倍あります。ここは素直に効きます。

Whisper 系モデルを Raspberry Pi 各機種で評価した研究でも、**Pi 5 の 4GB 版が
もっともコストパフォーマンスが良い**という結論になっています。同じ研究で、
`small` は Pi 5 でもリアルタイムを下回る（＝話した長さより認識に時間がかかる）と
報告されているので、**実機では `stt.model_size: base` を既定にしてください。**

Pi 4 を選ぶと `base` でも待ち時間が倍近くになり、返事まで6〜8秒級になります。
相づちで間を埋めてはいますが、この長さは子供には厳しいです。

Pi 5 の代償は「5V/5A 電源が要る」「発熱するので冷却が要る」の2点ですが、
**据え置き運用ならどちらも問題になりません。**

### なぜ ReSpeaker 2-Mics Pi HAT を勧めないのか

音質は良いのですが、**公式サポートが Pi Zero〜3B までで、Pi 5 は対象外**です。
専用ドライバ（seeed-voicecard）が Pi 5 のカーネルで素直に入らず、
そこで何日も溶かすことになります。まずは USB マイクで動かしてください。

### サーボの電源を Pi から取ってはいけない

SG90 は動き出しの瞬間に 1個あたり 700mA 近く流れます。2個同時に動くと
Pi の 5V が引きずられて、**再起動する・SD カードが壊れる**という壊れ方をします。

- サーボと LED の +5V は**別電源**から取る
- **GND だけは Pi と共通にする**（これを忘れると信号が伝わらない）

配線図は [README の「3. Raspberry Pi 実機」](../README.md#3-raspberry-pi-実機) にあります。

## 電源についての注意（Pi 5 特有）

Pi 5 は USB-C から **5V/5A（PD）** を要求します。
5V/3A の電源でも起動はしますが、**5A を検出できないと USB ポート全体の供給が
600mA に絞られる**仕様があります。

この構成は USB マイクと USB スピーカーの2台挿しなので、ここが直撃します。
症状は「マイクが認識されない」「スピーカーがブツブツ切れる」という形で出ます。
**必ず 5V/5A 対応の電源を使ってください。**

- [USB Power delivery on Raspberry Pi 5（公式ホワイトペーパー）](https://pip-assets.raspberrypi.com/categories/685-app-notes-guides-whitepapers/documents/RP-009856-WP-1-USB%20Power%20delivery%20on%20Raspberry%20Pi%205.pdf)

## 応答速度の目安

Pi 5 + faster-whisper small での実測見込みは **3〜5秒**です。
（PC 上の `--mock` より遅くなります。音声認識が CPU 実行のため）

遅いと感じたら、この順で調整してください。

1. `config.yaml` の `stt.model_size` を `small` → `base` に落とす（いちばん効く）
2. VOICEVOX を PC 側で動かし、`tts.url` をその PC に向ける
3. `llm.history_turns` を減らす

なお、**返事までの間は相づちと仕草で埋まっている**ので、3秒でも子供の体感は
それほど悪くありません。無音になるかどうかのほうが効きます。

## 持ち運びたくなったら（バッテリー駆動）

据え置きで完成させてからで構いません。ソフト側の変更は一切不要です。

Pi 5 は「モバイルバッテリーを挿せば動く」機器では**ありません**。
一般的な PD バッテリーは 5V では 3A までしか出さず、上記の 600mA 制限に落ちます。

現実的な方法は、**PPS トリガーケーブル**で本物の 5V/5A を引き出すことです。

| 部品 | リンク | 備考 |
|---|---|---|
| USB PD PPS トリガーケーブル 5V/5A | [B0CVGTZ457](https://www.amazon.co.jp/dp/B0CVGTZ457) | バッテリーに「5V 5A で出して」と交渉する |
| PPS 対応モバイルバッテリー 20000mAh | [B0CXNY69DC](https://www.amazon.co.jp/dp/B0CXNY69DC) | **仕様欄に「PPS」があり、5A を出せるものを選ぶこと** |

持ち時間の目安は、20000mAh（実効60Wh前後）で **8〜10時間**（会話は断続的な想定）。

ただし **Wi-Fi は必須**です（Claude API を呼ぶため）。
「持ち運べる」といっても、実質は家の中の移動だけになります。

### ぬいぐるみに入れるときの安全

子供が抱きしめるものなので、ここは省略しないでください。

- **バッテリーは縫い込まない。** 背中のファスナーポケットなど、すぐ取り出せる場所に
- **充電しながら遊ばせない。** 充電と稼働で発熱が重なる
- **一緒に寝かせない。** 布団の中は放熱できない
- Pi 5 は素手で触れないほど熱くなる。**ぬいぐるみの中で密閉しない**（通気穴を開ける）
